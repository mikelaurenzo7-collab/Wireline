# Precision Operator

Precision Operator is the single visual language for Wireline. It applies equally to personal and business agent configuration; those modes change workflows, templates, and wording, not color systems or page architecture.

Use a warm paper background, white operational surfaces, forest primary actions, precise 4px controls, 8px cards, Inter UI type, and JetBrains Mono only for technical labels and compact system metadata.

## Workspace route map

| Route | Source screens |
| --- | --- |
| `/studio` | Studio training and creation |
| `/agents` | Fleet roster plus empty, loading, and degraded states |
| `/knowledge` | Facts, rules, and empty knowledge state |
| `/actions` | Permissions and connections |
| `/ops` | Live operations, handoffs, and quality review |
| `/settings` | Workspace administration |

## Public and auth reference

The companion source export supplies Wireline’s landing, personal-agent marketing, pricing, solution, mobile, and sign-in compositions. Those surfaces use the same Precision Operator palette, typography, and geometry, with consumer-first copy and a clear business path.

## Rendering rules

- Do not force antialiased font smoothing or use synthetic font weights.
- Do not import broad compatibility, monochrome, readability, or geometry guard sheets.
- Do not use glass panels, gradients, large bubbly radii, or global utility repaint selectors.
- Preserve a fixed 212px desktop sidebar and a 16px mobile page margin.
