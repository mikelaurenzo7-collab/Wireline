# Page List & Route Contract

## Public Routes
- `/privacy`: Privacy Policy
- `/terms`: Terms of Service
- Auth: Handled by `AuthPortal` when no user session is present.

## Authenticated Routes
- `/`: Command Center (Default Landing)
- `/dashboard`: Operations Dashboard
- `/live`: Real-time Signal Presence / Live Monitor
- `/triage`: Inbox Triage / Lead Qualification
- `/logs`: Call Signal Archives
- `/inbox`: Omnichannel Relay (Email)
- `/outbound`: Outbound Signal (Dialer)
- `/appointments`: Commitment Registry
- `/train`: Cognitive Engine Training
- `/knowledge`: Knowledge Base / Personality Management
- `/agents`: Fleet Inventory Management
- `/integrations`: Third-party adapter configuration
- `/admin`: Platform Settings & Carrier Management
- `/dnc`: Network Exclusion Registry (DNC)
- `/audit`: Security Audit Logs
