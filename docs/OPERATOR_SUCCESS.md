# BotBound Success Playbook

How we win: people trust their **Bots** on the phone, in Studio, and in the outcomes they review.

## Activation Definition

A workspace is activated when the user has:

1. Created a Bot.
2. Trained it with role, facts, tone, rules, and escalation behavior.
3. Completed a private simulation or test call.
4. Launched a paid-plan number or clearly understands what remains before live launch.
5. Reviewed a real or simulated outcome in Studio.

## Onboarding Motion

1. **Build a Bot** - choose one clear job and outcome.
2. **Train the rules** - facts, approved answers, prohibited topics, escalation path, tone.
3. **Launch the channel** - paid-plan number, SMS/email, routing, approvals, billing controls.
4. **Run and review** - call, follow-up, log, coach, improve.

## Success Standards

- The Bot's personality matches the job.
- Every user gets a focused product without being pushed into an audience lane.
- Multi-Bot growth is clear: start with one, add specialists when needed.
- Every live workflow shows what happened, what was sent, and what needs approval.

## Coaching Prompts

- "What should this Bot never promise?"
- "When should it hand off to you?"
- "What is a successful outcome for this call?"
- "Which follow-up should happen automatically?"
- "What needs to be logged for review?"

## Red Flags

- The user thinks Free Builder includes a live production number.
- The user thinks BotBound only supports one Bot forever.
- Public-facing copy uses `AI employee` as the product noun.
- Launch copy still uses sub-$19 pricing.
- WhatsApp is described as publicly available before beta release.
