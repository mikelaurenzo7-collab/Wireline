02 ◆ UNDERSTAND

How a Call Happens

The magic moment, choreographed. A caller dials your number and twenty-two steps later their transcript, summary, and CRM record are written. This is the dance you should be able to recite in your sleep — because every "why didn't this work?" question lives somewhere on this timeline. 

sequenceDiagram
    autonumber
    actor Caller as "Caller"
    participant Tel as "Twilio / Carrier"
    participant Vapi as "Vapi runtime"
    participant Wire as "Wireline"
    participant Brain as "Claude / Gemini"
    participant DB as "Supabase Postgres"
    participant CRM as "CRM"
    participant Queue as "Webhook Queue"

    Caller->>Tel: "Dials your Wireline number"
    Tel->>Vapi: "Routes to assigned Vapi number"
    Vapi->>Wire: "POST /api/vapi-webhook (assistant-request)"
    Wire->>DB: "Look up agent config by phone number"
    DB-->>Wire: "Returns voice, prompt, archetype, first_message"
    Wire-->>Vapi: "Returns full assistant config"
    Vapi->>Caller: "Agent speaks first_message"
    Caller->>Vapi: "Responds in natural speech"
    Vapi->>Brain: "Streams transcript for next reply"
    Brain-->>Vapi: "Returns next utterance"
    Vapi->>Wire: "POST tool-call: book_appointment"
    Wire->>CRM: "Create lead and book slot"
    CRM-->>Wire: "Success"
    Wire-->>Vapi: "Tool result"
    Vapi->>Caller: "Confirms booking on the call"
    Caller->>Vapi: "Hangs up"
    Vapi->>Wire: "POST end-of-call-report"
    Wire->>Queue: "Queue async (immediate 200 OK)"
    Queue->>Brain: "Summary, lead-score, intent"
    Brain-->>Queue: "Enriched analysis"
    Queue->>DB: "Insert into wireline_call_logs"
    Queue->>CRM: "Sync transcript and outcome"

05 ◆ ACT

The Cheat Sheet

Symptom in, file path out. When something is wrong, find the row, copy the path, paste it into Claude Code with the fix you want. You will never again be stuck on "I do not know where to start." The starting line is always here.

Voice and Calls
Agent says the wrong thing, wrong tone, or wrong personality
src/lib/vapi-assistant-factory.ts + src/components/AgentTraining.tsx + src/components/KnowledgeBaseManager.tsx
Call does not connect or drops mid-call
src/lib/vapi-client.ts + src/routes/vapi-routes.ts   then check Vapi dashboard
Call completed but no log appears
src/lib/vapi-webhook-queue.ts + src/lib/vapi-handlers.ts   then check Sentry for queue errors
Want a new agent voice, accent, or provider
src/lib/agent-constants.ts   voice catalog + Vapi voice library
Tool call from agent fails (book appt, transfer, etc.)
src/lib/vapi-handlers.ts   find the specific tool function
Auth and Users
User cannot sign in
src/lib/auth-service.ts + src/middleware/auth.ts + src/components/AuthPortal.tsx   then Supabase auth logs
Password reset flow broken or missing
src/routes/auth-routes.ts   (Week 1 roadmap item)
Session expires too fast or too slow
src/lib/auth-service.ts   JWT lifetime config + INTERNAL_JWT_SECRET env
Billing and Stripe
Customer charged wrong amount
src/lib/stripe-helpers.ts + src/routes/billing-routes.ts + src/lib/plan-catalog.ts
Subscription status not updating in app
src/routes/webhook-routes.ts (Stripe webhook) + src/lib/spend-guards.ts
User hitting plan limits unexpectedly
src/lib/tenant-quotas.ts + src/lib/phone-line-entitlements.ts
Dashboard and UI
Dashboard shows wrong number or feels stale
src/lib/dashboard-stats.ts + src/lib/dashboard-cache.ts   60s TTL — call invalidateDashboard()
A page is broken or blank
src/routes/AppRoutes.tsx   find the route, then the page file in src/components/ or src/pages/
Need to change a label, button text, or copy
src/components/   tell Claude Code the exact phrase to search for
Compliance and Safety
DNC number was called
src/lib/compliance.ts + src/routes/compliance-routes.ts + wireline_dnc_list table
TCPA consent issue
src/lib/tcpa-consent.ts + audit log entries
Need to investigate a security event
src/lib/audit-logger.ts + src/routes/audit-routes.ts   then the /audit page
Integrations
CRM sync broken (HubSpot, Salesforce, Apollo)
src/lib/crm-service.ts + the provider file e.g. src/lib/hubspot-service.ts
Webhook not firing
src/routes/webhook-routes.ts + src/lib/webhook-helpers.ts + src/lib/webhook-validators.ts
Email send or receive issue
src/routes/email-routes.ts + src/lib/integrations.ts
Calendar sync (Google) broken
src/routes/calendar-routes.ts + check Google OAuth in src/routes/oauth-routes.ts
Data and Schema
Need a new field on agent, lead, or any entity
src/db/schema.ts   then run npx drizzle-kit push
Wrong data showing on a page
Find the route in src/routes/ that fetches it, trace to src/db/schema.ts
Want to run a one-off DB query
Supabase SQL editor for prod   or npx drizzle-kit studio for local dev
Performance and Errors
A page or API is slow
src/lib/dashboard-cache.ts + src/middleware/performance.ts   check cache hit rates
AI cost is too high
src/lib/claude-brain.ts   tier down Opus calls to Sonnet or Haiku
Error in production
Sentry dashboard first   then src/lib/sentry.ts + src/lib/sentry-events.ts
Rate limit hitting real users
src/lib/rate-limit.ts + src/middleware/api-rate-limits.ts + src/middleware/rate-limit-middleware.ts
06 ◆ ACT

The Command Palette

You speak business. Claude Code speaks code. This board is the translator. Pick the thing you want done, copy the ready-made prompt, paste it into Claude Code. Each prompt is calibrated to your exact codebase — file paths, conventions, and the tests Claude Code should run after.

I want to add a new field to my agents.
SCHEMA · MIGRATION · UI
Open src/db/schema.ts. Add a [TYPE] field named [FIELD_NAME] to the wirelineAgents table with an appropriate default. Then run: npx drizzle-kit generate, npx drizzle-kit push (with pooled POSTGRES_URL). Update src/components/AgentTraining.tsx to expose the new field in the agent editor UI. Add the field to the zod schema in src/lib/schemas.ts. Add an API test in src/routes/__tests__ to confirm round-trip persistence. Run npm run verify before stopping.
I want to add a new authenticated page.
ROUTE · COMPONENT · NAV
Create a new component at src/components/[PageName].tsx. Match the style of src/components/DashboardHome.tsx for consistency. Register the route in src/routes/AppRoutes.tsx behind auth gating. Add a navigation entry in src/components/AppShell.tsx and src/components/layout/. Update contracts/page-list.md to document the new route. Run npm run lint and npm run test:run.
I want to connect a new third-party integration.
SERVICE · REGISTRY · OAUTH
Create a new service module at src/lib/[provider]-service.ts. Mirror the structure and error handling of src/lib/hubspot-service.ts. Register it in src/lib/integrations-registry.ts so it appears on the /integrations page. Add the connector card UI in src/components/Integrations.tsx. If the provider needs OAuth, add the redirect handlers in src/routes/oauth-routes.ts and update src/lib/oauth-helpers.ts. Add a unit test alongside the new service file. Run npm run verify.
I want to change a pricing tier or plan limit.
BILLING · QUOTAS · STRIPE
Update plan definitions in src/lib/plan-catalog.ts. Sync corresponding Stripe product and price IDs in src/lib/stripe-helpers.ts. Update quota enforcement in src/lib/tenant-quotas.ts and src/lib/phone-line-entitlements.ts. Verify the spend cap routes in src/lib/spend-guards.ts handle the new tier. Run the Stripe billing tests and the spend-cap-routes.test.ts. Confirm /admin and the pricing page reflect the change.
I want to tune the AI cost down.
CLAUDE-BRAIN · TIERING · CACHE
Open src/lib/claude-brain.ts. Audit every callsite that uses complexity: "complex" — Opus at $15/M tokens. For each, evaluate whether the task can be served by Sonnet (medium, $3/M) or Haiku (simple, $1/M) without quality loss. Where caching is safe, add wrappers using src/lib/dashboard-cache.ts pattern. Update src/lib/claude-brain.test.ts to assert the new tier selections. Report the projected monthly savings.
I want to investigate why a customer's call failed.
FORENSICS · SENTRY · DB
Take the user_id and the rough timestamp. Open Sentry and filter by that user_id. Cross-reference the vapi_call_id in the wireline_call_logs table via Supabase SQL editor. Inspect src/lib/vapi-webhook-queue.ts for any failed end-of-call-report processing. Surface the failure point and the exact error. If you find a code-level fix, draft it but do not commit until I approve.
I want to add a new admin setting.
SETTINGS · SCHEMA · UI
Add a [TYPE] field [SETTING_NAME] to the wirelineSettings table in src/db/schema.ts. Push the migration. Update the AdminSettings UI in src/components/AdminSettings.tsx with the new control. Wire the read/write handlers in src/routes/settings-routes.ts. Add zod validation in src/lib/schemas.ts. Update the dev-context documentation if the setting affects environment variables.
I want to deploy a hotfix.
CI · VERCEL · MONITOR
Run npm run verify locally — it runs lint, full test suite, and build. Confirm green. Commit with a clear, specific message (no "fix stuff"). Push to main — Vercel auto-deploys via vercel.json. After the deploy, monitor Sentry for 15 minutes for any new error types. If anything spikes, walk back to "I want to roll back a deployment."
I want to roll back a bad deployment.
VERCEL · GIT · REVERT
Open the Vercel dashboard. Find the previous good deployment (look at the timestamp before the issue started). Click "Promote to Production." This restores the prior build immediately while we fix forward. Then in git: git revert HEAD; git push. Confirm the revert deploys cleanly and Sentry quiets down.
I want a new agent voice option in the dropdown.
VOICE · CATALOG · VAPI
Pick the voice from Vapi's voice library (note its voice_id and provider). Add it to the catalog in src/lib/agent-constants.ts under the appropriate provider group. Verify it appears in the voice dropdown in src/components/AgentTraining.tsx. Confirm src/lib/vapi-assistant-factory.ts maps the new voice_id correctly. Make one test call to a draft agent before promoting to production.
I want to add a number to the Do Not Call list.
COMPLIANCE · DNC
Use the /dnc UI in the app (preferred). For bulk uploads, insert directly into wireline_dnc_list via Supabase SQL. The compliance checks in src/lib/compliance.ts are wired into src/lib/agent-runtime.ts and will block any outbound dial to a DNC number automatically. Verify with one test outbound to a known DNC entry — it should fail at the runtime guard with a clear audit log entry.
I want to add an A/B test to an agent prompt.
EXPERIMENTS · AGENT TRAINING
Create two agent variants in /agents with different first_message and prompt configurations. Assign each to a different phone number in wireline_phone_numbers. Route a fraction of inbound traffic to each via Vapi number assignment. After 2 weeks, query wireline_call_logs grouped by agent_id and compare avg duration_seconds, lead_score, and intent_label distribution. Adopt the winner; archive the loser.
