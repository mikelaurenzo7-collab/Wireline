# Codebase Auditing Team Skill

**Role**: Autonomous team of agents specialized in comprehensive codebase auditing, health assessment, and improvement recommendations.

**Capabilities**:
- Static analysis, security scan, performance profiling
- Design system compliance check
- Code quality, duplication, and tech debt evaluation
- AI model integration health
- Full report generation with prioritized action list

**Integration**: Uses Grok default + tool calling for file access and analysis. Activated via agent prompt or Studio tool.

**Perfect for**: Regular maintenance and post-change QA in Wireline.
