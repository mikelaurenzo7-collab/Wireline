## 2026-06-14 - E2E tests skip on missing POSTGRES_URL
**Learning:** In the `verify` job, tests requiring a database are skipped if `POSTGRES_URL` is empty. However, the `e2e` job attempted to run the full Playwright suite without this skip logic. Since PRs from forks lack access to the `POSTGRES_URL` secret, providing a fallback fake PostgreSQL URL causes the underlying server boot to fail the `probeDatabase()` connection check, returning `503` on `/api/health` and failing the Playwright test suite.
**Action:** Just like the `db:health` and `tenant-isolation` checks in the `verify` job, the `e2e` job must contain explicit skip logic (using bash `if [ -z "${POSTGRES_URL}" ]; then ...`) so that E2E tests are skipped for external PRs lacking database credentials, rather than providing fake connection strings that cause the server to crash or reject health checks.
