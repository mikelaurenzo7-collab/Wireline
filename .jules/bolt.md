## 2024-03-24 - [React Context Memoization]
**Learning:** This codebase uses React Context heavily for global state (e.g., Auth, Theme, Toast, Branding). A common performance anti-pattern found was passing inline object literals directly to `Context.Provider`'s `value` prop (e.g., `value={{ user, session, loading }}`). This defeats React's object identity checks and forces all context consumers to re-render whenever the provider re-renders, even if the actual context data hasn't changed.
**Action:** Always wrap the value passed to a `Context.Provider` in a `useMemo` hook, and ensure any functions included in that value are wrapped in `useCallback`. This preserves reference equality for the context value and prevents cascading unnecessary re-renders across the application.
