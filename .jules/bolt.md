## 2026-06-14 - Unmemoized Filtering on Renders
**Learning:** In heavily used list components like `CallLogs`, `SmsThreads`, and `DncManager`, the list filtering (and sometimes mapping) logic happens on every single render. Since `calls` / `threads` arrays can be large, running `.filter()` string operations on every keystroke or selection change causes unnecessary CPU churn and React tree diffing operations, particularly when only the active selection changes but the search/filter criteria stay the same.
**Action:** Wrap these heavy array filtering operations in `useMemo` with dependency arrays limiting their execution to when `search`, `filter`, or the source data (`calls`, `threads`, etc.) actually change.
## 2026-06-14 - E2E Tests Environment Missing Secrets
**Learning:** The E2E tests run on GitHub Actions using Playwright, but when trying to boot the local test server, they require specific secrets (like `INTERNAL_JWT_SECRET` of at least 32 characters) to authenticate test sessions correctly. If this secret is missing from the workflow `.yml` environment for the `e2e` job, the tests will immediately fail upon authentication.
**Action:** When adding or fixing GitHub Action workflows containing Playwright test runs, ensure `INTERNAL_JWT_SECRET` (and other critical vars) are set in the `env` section of the testing job or step, using secrets or a hardcoded fallback test key that satisfies the 32+ character requirement for local dev/testing.
