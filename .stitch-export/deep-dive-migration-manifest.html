# Wireline Deep-Dive Migration Manifest: Design-to-Code Parity This document provides granular, platform-specific implementation instructions for the Ametrine Precision v1.0 design system. ## 1. Global Tokens (Tailwind CSS / React) Add these to your `tailwind.config.js` to lock in the Ametrine theme. ```javascript module.exports = { theme: { extend: { colors: { primary: { DEFAULT: '#5d3fd3', // Ametrine Purple variant: '#4b32b3', container: '#e0e7ff', }, surface: { base: '#f8f9ff', dim: '#cbdbf5', bright: '#f8f9ff', container: { lowest: '#ffffff', low: '#eff4ff', high: '#e0e7ff', } }, outline: { variant: '#d1d5db', } }, fontFamily: { sans: ['Hanken Grotesk', 'sans-serif'], }, borderRadius: { 'base': '4px', } } } } ``` ## 2. iOS Implementation (SwiftUI) Create a `Theme.swift` file to manage the Ametrine palette. ```swift import SwiftUI struct AmetrineTheme { static let primary = Color(hex: "5D3FD3") static let surface = Color(hex: "F8F9FF") static let surfaceContainerLow = Color(hex: "EFF4FF") static let cornerRadius: CGFloat = 4.0 struct Typography { static func headline() -> Font { return .custom("HankenGrotesk-Bold", size: 24) } } } ``` ## 3. Android Implementation (Jetpack Compose) Update your `Color.kt` and `Type.kt`. ```kotlin // Color.kt val AmetrinePrimary = Color(0xFF5D3FD3) val AmetrineSurface = Color(0xFFF8F9FF) val AmetrineSurfaceVariant = Color(0xFFE0E7FF) // Theme.kt private val LightColorScheme = lightColorScheme( primary = AmetrinePrimary, surface = AmetrineSurface, onPrimary = Color.White ) ``` ## 4. Design System Audit Logic Every screen in the monorepo MUST be audited against these three pillars: 1. **Color Contrast:** All interactive elements must use `--color-primary` (#5d3fd3). 2. **Spacing Grid:** Strictly adhere to the 4px base unit. Card padding is fixed at 12px. 3. **Corner Radius:** All buttons, cards, and input fields must use a 4px radius. No exceptions for "pills" unless they are status badges. ## 5. Execution Strategy - **Web:** Search and replace all instances of `blue-600` or `#0052ff` with `primary`. - **Mobile:** Update `Assets.xcassets` (iOS) and `colors.xml` (Android) to the new hex codes.
