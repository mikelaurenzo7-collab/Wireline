# Wireline Technical Specification & Handoff Guide ## Project Overview Wireline is a premium AI communications platform. This guide provides the structural, stylistic, and functional requirements for translating the current high-fidelity designs into production code across Web (React/Tailwind), iOS (SwiftUI), and Android (Kotlin/Compose). ## 1. Visual Identity (Ametrine Precision) - **Primary Brand Color:** #5d3fd3 (Purple) - **Secondary/Surface:** #f8f9ff (Light), #121212 (Dark) - **Typography:** Hanken Grotesk (Sans-serif) - **Roundness:** 4px (Subtle, professional) - **Tone:** Premium, Capable, Trustworthy. ## 2. Platform-Specific Implementation ### Web App (Desktop) - **Architecture:** Responsive SPA (Single Page Application). - **Navigation:** Fixed sidebar for main hubs; top app bar for workspace switching and notifications. - **Components:** Modular cards with readiness scores, live activity feeds, and deep-dive configuration tabs in Agent Studio. - **Interaction:** Progressive disclosure for advanced agent settings. ### Apple iOS (SwiftUI) - **App:** Tab-based navigation (Overview, Inbox, Assistants, Settings). - **Dynamic Island / Live Activity:** - **Compact:** Show agent screening status (e.g., "Screening..."). - **Expanded:** Active call controls, transcript snippet, and human intervention toggle. - **Widgets:** Home screen (Small/Medium) showing coverage rate and pending handoffs. ### Android - **Material Design 3:** Utilize Material You for system-level integration. - **Rich Notifications:** High-priority channels for 'Qualified Leads' and 'Urgent Handoffs' with direct action buttons. - **Widgets:** 4x2 interactive widgets for agent status toggles. ### CarPlay - **Interface:** Voice-first. Simplified list views and large-target buttons. - **Use Case:** Focus on screening calls while driving and quick calendar triage. ## 3. Core Functional Flows - **Handoff Logic:** Trigger a high-priority notification to the human team when agent confidence < 75% or specific keywords (e.g., "urgent", "cancel") are detected. - **Knowledge Sync:** Multi-source ingestion (PDF, Web, Notion) with a 'Freshness' validator UI. - **Simulation:** A 'Sandbox' environment for testing agent behavior before publishing to live channels. ## 4.
