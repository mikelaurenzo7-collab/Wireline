# Monorepo Integration & Component Specification ## 1. Directory Structure (Recommended) ```text /packages /design-system (Ametrine Precision Tokens & Base UI) /web-app (React + Tailwind) /mobile (Shared business logic) /ios (SwiftUI) /android (Kotlin Compose) ``` ## 2. Global CSS Variables (Tailwind / Web) Apply these to your global CSS entry point to match the Ametrine Precision theme: ```css :root { --color-primary: #5d3fd3; --color-surface: #f8f9ff; --font-main: 'Hanken Grotesk', sans-serif; --radius-base: 4px; } ``` ## 3. Core Component Mapping ### Navigation (Web) - **SideNavBar:** Fixed 256px width. Use `bg-surface` with `border-r border-outline-variant`. Active state: `bg-primary text-white`. - **TopAppBar:** 64px height, `backdrop-blur-md` background. ### Cards & Surfaces - **Base Card:** `bg-white`, `rounded-base`, `border border-outline-variant`. - **Readiness Badge:** Success (`bg-success-container text-on-success`), Warning (`bg-warning-container text-on-warning`), Danger (`bg-error-container text-on-error`). ### Native Implementation (Mobile) - **iOS (SwiftUI):** Use `Color("Primary")` mapped to `#5d3fd3`. Standard `RoundedRectangle(cornerRadius: 4)`. - **Android (Compose):** Update `Theme.kt` with `primary = Color(0xFF5D3FD3)`. Use Material 3 `Shape` tokens for consistency. ## 4. Interaction Patterns - **Handoffs:** Modal overlay with real-time transcript sync and intervention controls. - **Simulation:** Use a split-pane layout for configuration vs. real-time feedback. ## 5. Asset Manifest All logos and platform icons have been exported as SVGs with consistent stroke weights (1.5px or 2px) to match the premium, professional tone.
