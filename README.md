# Wireline

Inbound & Outbound AI Agents for Sales, Support & Operations

**New Feature Spotlight (June 2026)**: **CarPlay Agents Widget**

Drive time is now productive time. Wireline users can interact with their specialized agents hands-free via CarPlay:

- Glanceable widget with quick actions and status
- Voice-first conversational mode with full agent context
- Smart incoming call handoff: Let your agent screen, qualify, or handle calls while you drive safely

This native iOS experience is built directly in the monorepo for seamless integration with agents, auth, and the premium Aurora Cream design system.

See `docs/carplay-architecture.md` for full details, architecture, and roadmap.
