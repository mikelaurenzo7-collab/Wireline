Wireline

Claude Connector

Wireline is a remote MCP server for Claude, Claude Code, ChatGPT, and Cursor. New users create a Wireline account during OAuth, then build their first voice agent in Claude. Privately rehearse it, optionally save Training after enabling that permission in Apps, and continue in Wireline for numbers and launch. This is not a repo voice SDK.

MCP endpoint: https://trywireline.com/mcp
Transport: Streamable HTTP
Auth: OAuth 2.0 with PKCE S256. Claude.ai uses dynamic client registration. Claude Code uses Anthropic’s Client ID Metadata Document.

What you can do from Claude

  • Create a Wireline account during Connect if you are new.
  • Build your first confirmed private agent draft in that workspace.
  • Read or update that draft after another explicit confirmation.
  • List agents and inspect one agent’s next step without seeing phone numbers or customer records.
  • Inspect aggregate workspace status without customer identities or message bodies.
  • Read owner-authored Training and, after the Apps toggle, save a confirmed fact or rule.
  • Start a short, tool-free private voice simulation of a saved draft.
  • Trigger a private text rehearsal of an owned agent. This is not a live call.

What stays in Wireline

  • Phone-number purchase or attachment.
  • Live inbound or outbound calling and messaging.
  • Integrations, billing, and agent launch.
  • Call recordings, transcripts, and customer records.

Add as a custom connector

In Claude, open Settings → Connectors, add a custom connector, and enter https://trywireline.com/mcp. Create a Wireline account if you do not have one, then allow the connection. Directory listing, when published, appears at Claude’s Connectors Directory under the slug wireline.

Claude Code

Claude Code connects with Anthropic’s published client metadata and a loopback callback. Wireline accepts http://localhost/callback and http://127.0.0.1/callback with the port ignored, as required for native clients.
