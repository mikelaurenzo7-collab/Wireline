BotBound

Cursor Plugin

BotBound meets you in Cursor so you can create an account and build your first Bot without leaving the chat. ChatGPT and Claude share the same remote MCP server. Live calls, numbers, email on eligible plans, billing, and launch stay in BotBound. This is not a repo voice SDK.

MCP endpoint: https://botbound.app/mcp
Transport: Streamable HTTP
Auth: OAuth 2.0 with PKCE S256. Cursor registers dynamically against Cursor operated callbacks. No API keys in the plugin.

Add BotBound to Cursor installs the remote MCP server in one click. Cursor then runs OAuth. There is no API key.

Install in Cursor

  1. Click Add BotBound to Cursor, install from Cursor Directory when listed, or add a remote MCP server with URL https://botbound.app/mcp.
  2. Complete OAuth. Create a BotBound account if you do not have one, then allow Cursor.
  3. Ask Cursor to create your first personal assistant, front desk, scheduling, or support Bot, then privately rehearse a conversation.

Manual Config

Paste this into Cursor MCP settings. Do not add headers, API keys, or an auth client secret. Cursor discovers OAuth from BotBound's well known metadata. The legacy technical server key remains wireline during the migration.

{
  "mcpServers": {
    "wireline": {
      "url": "https://botbound.app/mcp"
    }
  }
}

What You Can Do from Cursor

  • Create a BotBound account during Connect if you are new.
  • Build your first confirmed private agent draft in that workspace.
  • List agents and inspect one agent's next step without seeing phone numbers or customer records.
  • Trigger the agent in a private text rehearsal, or start a short tool free private voice simulation.
  • Save a confirmed Training fact or rule after you enable that permission in BotBound Apps.

Personal Calls

Connect a personal Bot with a paid Calls plan, then ask Cursor to prepare a personal service or coordination call. Grant the new call permissions when prompted. Open the review link, check the recipient and instruction, choose a granted recipient permission, and select Place call in BotBound. Cursor can then check the call's status. Claude and ChatGPT use the same tools and review flow.

The initial scope is Illinois callers and recipients with captured permission. Preparing a call does not contact anyone. Proposals expire after 24 hours, and carrier acceptance does not mean the requested task succeeded.

Business Bots can handle incoming calls. Business outbound calling and SMS are coming soon.

What Stays in BotBound

  • Phone number purchase or attachment.
  • Live incoming calls, permitted personal calls, and email on eligible plans.
  • Integrations, billing, and agent launch.
  • Call recordings, transcripts, and customer records.
  • Any attempt to embed BotBound as a voice SDK inside another repository.
