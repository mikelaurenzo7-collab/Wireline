BotBound

Cursor plugin

BotBound meets you in Cursor so you can create an account and build your first voice agent without leaving the chat. ChatGPT and Claude share the same remote MCP server. Live calls, numbers, messaging, billing, and launch stay in BotBound. This is not a repo voice SDK.

MCP endpoint: https://trywireline.com/mcp
Transport: Streamable HTTP
Auth: OAuth 2.0 with PKCE S256. Cursor registers dynamically against Cursor-operated callbacks. No API keys in the plugin.
Compatibility: the MCP protocol endpoint remains on the legacy service host while existing OAuth registrations complete their BotBound domain transition.

Add BotBound to Cursor — one-click install of the remote MCP server. Cursor then runs OAuth. There is no API key.

Install in Cursor

  1. Click Add BotBound to Cursor, install from Cursor Directory when listed, or add the compatibility MCP service URL shown above.
  2. Complete OAuth. Create a BotBound account if you do not have one, then allow Cursor.
  3. Ask Cursor to create your first receptionist, scheduler, sales, or support voice agent, then privately rehearse a customer line.

Manual config

Paste this into Cursor MCP settings. Do not add headers, API keys, or an auth client secret. Cursor discovers OAuth from BotBound's well-known metadata. The stable technical server key remains wireline for connected-client compatibility.

{
  "mcpServers": {
    "wireline": {
      "url": "https://trywireline.com/mcp"
    }
  }
}

What you can do from Cursor

  • Create a BotBound account during Connect if you are new.
  • Build your first confirmed private agent draft in that workspace.
  • List agents and inspect one agent's next step without seeing phone numbers or customer records.
  • Trigger the agent in a private text rehearsal, or start a short tool-free private voice simulation.
  • Save a confirmed Training fact or rule after you enable that permission in BotBound Apps.

What stays in BotBound

  • Phone-number purchase or attachment.
  • Live inbound or outbound calling and messaging.
  • Integrations, billing, and agent launch.
  • Call recordings, transcripts, and customer records.
  • Any attempt to embed BotBound as a voice SDK inside another repository.
